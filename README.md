# Mi Malla Curricular

Plataforma web diseñada para que los estudiantes puedan organizar sus materias y hacer seguimiento a su progreso académico.

## Funciones principales

- Registro de estudiantes.
- Creación de materias por semestre.
- Seguimiento de materias aprobadas.
- Carga de la malla curricular en imagen o PDF.
- Visualización del avance académico.

## Objetivo

Facilitar la organización y el seguimiento de la vida académica de los estudiantes.
